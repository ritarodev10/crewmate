# Shared Conventions

Rules that apply to both `apps/api` and `apps/web`. Every engineer working on this monorepo should read all three files before writing code.

---

| File | Description |
|---|---|
| [typescript.md](typescript.md) | Strict TypeScript rules: `interface` vs `type`, no `any`, null safety, `satisfies`, path aliases |
| [naming.md](naming.md) | Consistent naming for files, folders, variables, events, stores, query keys, and CSS properties |
| [git.md](git.md) | Branch prefixes, conventional commit format, commit discipline, PR merge rules |
